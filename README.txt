موقع تفاصيل تطبيق قنوات
========================
الملفات:
- index.html: صفحة الموقع
- assets/screenshot-1.png إلى screenshot-6.png: الصور التي أرسلتها

لتفعيل زر تحميل APK:
1. انسخ ملف التطبيق APK إلى نفس المجلد الموجود فيه index.html.
2. غيّر اسم الملف إلى app.apk.
3. ارفع مجلد الموقع كاملًا إلى Netlify أو استضافة تدعم الملفات الثابتة.
4. جرّب زر "تحميل التطبيق APK".

التخصيص:
- الاسم والمميزات والإصدار والمطور موجودة في index.html.
- معرّف التواصل مضبوط على @k9_8i ورابط Telegram https://t.me/k9_8i.
- معرض الصور يتحرك تلقائيًا ويتبدل اتجاهه كل ثانية، ويتوقف عند تمرير المؤشر عليه.

ملاحظة: هذه صفحة HTML/CSS/JavaScript عادية وليست مشروع Flutter. إذا كنت تقصد بناء تطبيق Flutter فعلي، فهذا مشروع مختلف.
